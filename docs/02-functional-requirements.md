## D. Aturan lintas modul

- Validasi lewat `FormRequest` di `app/Http/Requests/Admin`; pesan kesalahan Bahasa Indonesia.
- Semua field file/gambar memakai komponen `MediaField` dan aturan `MediaPath`.
- HTML dari editor (artikel, klarifikasi, deskripsi portofolio dan layanan) disaring `App\Services\HtmlSanitizer::clean()` **saat dirender** di controller publik: hanya tag/atribut yang dihasilkan Tiptap yang lolos (termasuk `figure.wp-block-image`, callout, `pre[data-code-theme]`, tabel); `script`/`iframe`/`svg`/`form` dibuang beserta isinya, atribut `on*` dibuang, tautan hanya `http(s)/mailto/tel`/relatif, gambar hanya `http(s)`/relatif, `style` dibatasi ke `color`, `background-color`, `text-align`, `width` (%). Data lama di database ikut tersaring tanpa migrasi. Setiap `{@html}` baru wajib melewati sanitizer ini.
- Seluruh respons web membawa header `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` (kamera/mikrofon dimatikan, geolokasi hanya situs sendiri), dan `Strict-Transport-Security` (hanya lewat HTTPS, tanpa `includeSubDomains`) lewat middleware `SecurityHeaders`. `Content-Security-Policy-Report-Only` juga dikirim (belum memblokir; pelanggaran hanya tampil di konsol browser). Setelah dipantau tanpa pelanggaran pada halaman utama, ganti ke `Content-Security-Policy` (lihat `06` #10).
- Cookie sesi bertanda `Secure` di produksi (`SESSION_SECURE_COOKIE` di `docker-compose.prod.yml`).
- Perubahan perilaku wajib disertai tes Pest di `tests/Feature`.

**Cloudflare Turnstile.** Form publik (`login`, `register`, `password.email`, `password.update`, `POST /contact`, ulasan portofolio, `blog.comments.store`) dilindungi middleware `VerifyTurnstile` (daftar rute di `PROTECTED_ROUTES`) yang memverifikasi field `cf-turnstile-response` lewat `TurnstileService`. Aktif hanya bila `turnstile_site_key` dan `turnstile_secret_key` (grup **Keamanan** di Pengaturan Sistem) terisi; gagal verifikasi atau Cloudflare tak terjangkau → ditolak (fail closed). Widget: `components/turnstile.svelte`, site key dibagikan lewat shared prop `turnstileSiteKey`. Pengecualian terdokumentasi: `passkey.login` (tanda tangan WebAuthn) dan `two-factor.login.store` (hanya sesudah login yang sudah diverifikasi); tes `every public POST route is challenged` menggagalkan build bila ada rute POST publik baru yang tidak terdaftar.

**Peran & otorisasi.** `UserRole`: `admin`, `redaktur`, `user`. Registrasi selalu membuat `user` (tanpa akses admin); hanya admin yang dapat mengubah peran lewat `/admin/users`. Gate `manage-site` (admin saja) melindungi seluruh area admin kecuali area blogging; gate `manage-blog` (admin + redaktur) melindungi `posts`, `post-categories`, `tags`, `blog-comments`, serta `media.browse`/`media.store` untuk editor artikel. Penegakan di level rute (`can:` middleware) dan `BlogCommentPolicy`; menu sidebar hanya cermin UI. `/admin` (dasbor) mengalihkan akun `user` ke beranda. Admin tidak dapat menghapus akunnya sendiri, dan admin terakhir tidak dapat dihapus atau diturunkan perannya (`UserController`), agar situs tidak kehilangan pengelola.

**Pratinjau draf artikel.** `GET /blog/{slug}?action=preview&cache={hash}` menampilkan artikel yang belum terbit hanya untuk staf pengelola blog (`canManageBlog`) dengan `hash` valid (`Post::previewHash()`: HMAC slug + waktu simpan terakhir, jadi setiap penyimpanan membuat tautan lama tidak berlaku); selain itu 404. Halaman pratinjau `noindex,nofollow`. Tombol buka pratinjau ada di dalam kotak judul editor artikel (tautan publik bila terbit, tautan pratinjau bila draf).

**Komentar blog.** `BlogComment` (terpisah dari `PortfolioRating`): pembaca yang login berkomentar/membalas di `POST /blog/{slug}/comments` (throttle + Turnstile). Isi komentar ditulis lewat editor WYSIWYG mode `minimal` (formulir komentar dan balasan; admin juga memakainya di modal ubah), disanitasi server (`SanitizesRichText`, maks. 5000) dan disanitasi lagi saat ditampilkan. Komentar pengguna berstatus `pending` sampai disetujui; komentar admin/redaktur langsung `approved`. `parent_id` harus komentar `approved` pada artikel yang sama (kedalaman data tak terbatas; UI berhenti menjorok setelah 4 tingkat). `user_id`, `post_id`, `parent_id`, `status` tidak pernah mass-assignable dari klien. Menghapus komentar mengangkat balasannya satu tingkat (ke induk komentar yang dihapus); menolak (`rejected`) komentar menyembunyikan seluruh cabangnya di halaman publik. Admin: `/admin/blog-comments` (index, show/telusur thread, update isi+status, delete; tanpa create).

> URL publik lama berbahasa Indonesia (`/karir`, `/pendidikan`, `/penghargaan`, `/kontak`, `/layanan[/{slug}]`, `/portofolio[/{slug}]`, `/tentang/{saya,situs,skill}` (`/tentang/saya` → `/about`), `/sumber-daya/tempat-ngopi`) dialihkan 301 ke URL berbahasa Inggris di `routes/web.php`. Sitemap hanya memuat URL baru.
